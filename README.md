# All God's Children Foundation website

## Upload to GitHub Pages

1. Extract this ZIP file on your computer.
2. Upload the **contents** of the extracted folder to the root of your GitHub Pages repository. `index.html` should be directly in the repository root, alongside `styles.css`, `script.js`, and the other HTML pages.
3. Keep the `images` folder and its contents in the same place; the pages rely on those relative paths.
4. In GitHub, open **Settings → Pages** and confirm that the site is published from the intended branch and repository root.

The site uses plain HTML, CSS and JavaScript and does not require a build step. Organization registration wording and child-safeguarding notes have been retained in the site content.
